# Security Policy

## Reporting a security problem

If you find a security vulnerability in https://tavernapi.com, the API endpoints (`/v1`, `/v1beta`), or the console (https://tavernapi.com/console), report it privately by email:

- **Email:** `support@tavernapi.com`
- **Subject line:** Include `Security` in the subject

Do not report security problems in a public GitHub issue or pull request.

## What to include

A clear report helps us verify and fix the problem. Please include:

- What you found and where it happens (URL, endpoint, or console page)
- Step-by-step instructions to reproduce the problem, including sample requests or responses if relevant
- The potential impact if the issue were exploited

Never include real users' data or anyone's API key in your report. If you need to refer to a key, use `sk-tav-...` or only the last four characters shown in the console.

## Testing rules

When checking a potential vulnerability:

- Use only your own account and do not access or modify other people's accounts or data
- Do not run load tests, automated scanners, or spam against the website, console, or API
- Give us time to fix the problem before publishing any details
